# Дизайн

[Figma](https://www.figma.com/design/Jl1HPYCBxoZwrjLHXg0h1e).
Скриншоты экранов — в [screens/](screens/).

Утверждённое оформление не менять без явной просьбы.
Цвета и эффекты заданы переменными в начале `app/frontend/src/styles.css`.
Основной размер — 390×844; на компьютере интерфейс показан в рамке телефона.

Фотографии в `app/frontend/public/img` — временное оформление из интернета.
Изображения демо-мест Иванова взяты с Викисклада;
линия маршрута на карте построена OSRM по данным OpenStreetMap.
