# Проверки

Из корня проекта после установки `requirements.txt`:

```bash
source .venv/bin/activate
python -m pytest tests -q
```

Проверяются BM25 и предобработка, схемы API, HTTP-обмен с тестовым генератором,
подключение фабрики и цепочка BM25 → выбор мест → OSRM с тестовыми HTTP-ответами.
Внешние LLM и OSRM
этими тестами не вызываются. Проверяются ограничения на один день, выбор только
из трёх найденных документов и использование координат корпуса. Если в окружении есть HTTP-прокси, добавьте
`127.0.0.1,localhost` в `NO_PROXY` для HTTP-тестов.

Поисковый прогон: `python -m benchmark.run` — [инструкция](../benchmark/README.md).
Фронтенд: `cd app/frontend && npm run build`.
Карточки, вопросы, эталоны и ответы просматриваем вручную.
