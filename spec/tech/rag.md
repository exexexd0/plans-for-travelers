# RAG и BM25

## Сейчас

Поиск и LLM пока не реализованы. Места заготовлены в `state.ts`.

## Требования

1. Реализовать собственный BM25 с одинаковой предобработкой документов и запроса.
2. Загружать корпус из файла и строить индекс при запуске бэкенда.
3. Возвращать найденные документы с ID и баллами BM25 через контракт поиска.
4. Передавать модели найденные документы и проверять ID выбранных мест.
5. Для вопросов без сведений в корпусе обеспечить отказ.

Корпус, предобработка, формула и параметры BM25 должны быть зафиксированы
для повторяемой проверки. Готовые поисковые индексы запрещены.

## Корпус

Для текущей контрольной точки выбран окончательный корпус: места Иванова.

## Проверка по требованиям курса

30 документов; 10 обычных вопросов с эталоном и минимум тремя релевантными
документами на каждый; 5 вопросов без ответа. Сохранить выдачу и ответы.
Метрики: Recall@k, MRR, Accuracy, Correct Rejection Rate.
Подробнее: [benchmark](../../benchmark/README.md).
