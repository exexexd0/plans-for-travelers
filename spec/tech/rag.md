# RAG

## Откуда сейчас берётся маршрут

Маршрут собирает функция `buildRoute(plan)` в `app/frontend/src/state.ts`, без поиска и без LLM:

- для каждого выбранного интереса в коде лежит короткий список заготовленных названий мест;
- на каждый день берётся пять мест по кругу из списков выбранных интересов;
- название дня берётся из заготовленного списка, текст карточки дня составляется из названий мест;
- описание поездки составляется из числа дней и выбранных интересов.

Город на результат не влияет, кроме одного случая: для города «Иваново» первый день — пять заготовленных реальных мест с фотографиями и картой.
