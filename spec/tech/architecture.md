# Архитектура

Однодневное приложение: React + TypeScript → FastAPI → собственный BM25 → LLM → OSRM.
Один файл корпуса — один поисковый документ, содержащий несколько мест.

## Папки

| Путь | Назначение |
|---|---|
| `app/frontend/src/` | Интерфейс, HTTP-клиент, карта Leaflet |
| `app/backend/main.py` | FastAPI, endpoint, подключение генератора, обработка ошибок |
| `app/backend/api/schemas.py` | Формат запроса и ответа, только days=1 |
| `app/backend/pipeline_adapter.py` | Соединение BM25, выбора мест и OSRM с API |
| `app/backend/domain/models.py` | Place, SearchDocument, SearchHit без HTTP-зависимостей |
| `app/backend/application/ports.py` | Контракт поиска |
| `app/backend/infrastructure/search/` | Собственный BM25 и общая предобработка |
| `app/backend/infrastructure/corpus/loader.py` | Загрузка 30 документов |
| `app/backend/infrastructure/llm/client.py` | OpenAI-совместимый вызов LLM и проверка формата ответа |
| `app/pipeline/rag/routing.py` | Используемый клиент OSRM и обработка его ответа |
| `app/backend/data/ivanovo/` | 30 категорий, 336 мест, индивидуальные тексты |
| `benchmark/` | 15 вопросов, поисковые метрики и сохранённая выдача |
| `tests/` | Проверки BM25, API и соединения компонентов |

## Путь запроса

1. Пользователь выбирает город, интересы, дату и при желании вводит пожелания.
2. `buildRoute` вызывает HTTP-клиент, который отправляет POST `/api/v1/trips/generate`.
3. API проверяет запрос; генератор ищет три документа через тот же BM25, что в benchmark.
4. LLM получает места и тексты только этих документов, возвращает название
   прогулки, упорядоченные ID мест и признак нехватки контекста.
5. Генератор проверяет уникальность ID и принадлежность найденным документам.
   Названия, описания, адреса и координаты берутся из корпуса.
6. OSRM строит пеший путь в выбранном порядке. Для одной точки геометрии нет.
7. API возвращает один день; фронтенд показывает карту и карточки мест.

Модель не генерирует координаты и сведения о местах. Документы и отзывы —
данные, не инструкции. При нехватке контекста показывается
«Тестовый режим, мест пока не много». При сбое сервиса API возвращает ошибку.
Изображения пока отсутствуют в корпусе; интерфейс использует существующие заглушки.

## Корпус и поиск

Файл имеет id D01–D30, name, city, category и places. У каждого места свой text,
исходный ID, адрес, координаты и source. Общего text в JSON нет:
загрузчик соединяет описания в памяти для индекса. ID вложенного места не является
отдельным документом. Фильтры и исключения BM25 относятся к документам.

Индекс строится один раз при создании генератора. k=3, k₁=1,2, b=0,75.
Предобработка документов и запросов одинакова: лемматизация и стоп-слова.
Подробности — в [rag.md](rag.md), формат HTTP — в [api-contract.md](api-contract.md).

## Настройки и зависимости

`.env`: ROUTERAI_API_KEY, ROUTERAI_BASE_URL, CHAT_MODEL, OSRM_BASE_URL,
необязательный CORPUS_PATH. Путь корпуса по умолчанию — app/backend/data/ivanovo,
относительные пути считаются от корня проекта. Секреты в Git не добавляются.
TRIP_GENERATOR_FACTORY позволяет заменить генератор для проверок.

Корневой requirements.txt включает app/backend/requirements.txt.
PostgreSQL, pgvector, эмбеддинги, старый граф и Jev не нужны для запуска API.
Их исходный код сохранён, зависимости отделены в app/pipeline/requirements.txt.
Compose запускает OSRM. Карта фронтенда использует leaflet и @types/leaflet.
