# Архитектура

Статус: фронтенд реализован; всё, что правее него на схеме, — проект, кода пока нет.

## Компоненты

```
┌────────────┐   HTTP/JSON   ┌────────────┐   запрос   ┌──────────────┐
│  Фронтенд  │ ────────────> │    API     │ ─────────> │ BM25-индекс  │
│ React+Vite │ <──────────── │ (бэкенд)   │ <───────── │ (в памяти)   │
└────────────┘    маршрут    └─────┬──────┘   top-k    └──────┬───────┘
                                   │                          │ строится при старте
                                   │ top-k + настройки        ▼
                                   ▼                    ┌──────────────┐
                             ┌────────────┐             │   Корпус     │
                             │    LLM     │             │ (файл с      │
                             └────────────┘             │  местами)    │
                                                        └──────────────┘
```

## Путь запроса

1. Пользователь проходит шаги 1–4 и нажимает «Всё верно, вперёд».
2. Фронтенд отправляет на API город, интересы, длительность и дату начала.
3. API проверяет, что город есть в корпусе, и строит поисковый запрос из интересов.
4. Запрос проходит ту же предобработку, что и документы, и уходит в BM25-индекс.
5. Индекс возвращает top-k мест этого города.
6. API передаёт найденные места и настройки поездки в LLM. LLM раскладывает места по дням и пишет описание.
7. API проверяет, что LLM использовала только найденные места, и возвращает маршрут.
8. Фронтенд показывает экран «Поездка» и «Маршрут по дням».

## Фронтенд

Код в `app/frontend/src`:

| Файл | Что в нём |
|---|---|
| `App.tsx` | состояние поездки (`Plan`) и текущий шаг; переключение экранов |
| `state.ts` | типы, список интересов и городов, форматирование дат, `buildRoute` |
| `ui.tsx` | общие элементы: экран с фоном, кнопки, чипы, иконки, прогресс |
| `screens/*.tsx` | семь экранов сценария |
| `styles.css` | все стили; цвета и «стекло» — переменными в начале файла |

Точка интеграции одна: функция `buildRoute(plan)` в `state.ts`. Сейчас она возвращает демонстрационный маршрут. При подключении бэкенда она заменяется на запрос к API, который выполняется на экране генерации.
