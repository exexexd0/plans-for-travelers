# API однодневного маршрута

`POST /api/v1/trips/generate` принимает JSON: `city`, `interests`, `days: 1`,
`start` (дата YYYY-MM-DD не раньше текущей по календарю сервера), необязательный
`prompt`. Значения интересов: kids, food, nature, buildings, art, active, unusual.
Текущий корпус содержит места Иванова.

Ответ: `city`, `description`, `image_url`, `days` с одним днём (`date`, `title`,
`summary`, `image_url`, `stops`, `route`). Место содержит `id`, `name`,
`address`, `description`, `image_url`, `latitude`, `longitude`. Для сохранения
предыдущего отображения `description` содержит исходную рубрику места. Маршрут —
GeoJSON LineString с координатами [долгота, широта] или null для одной точки.
Порядок списка соответствует итоговому порядку маршрута. Фотографии пока null,
фронтенд показывает согласованные заглушки.

## Построение

Планировщик получает город, интересы и пожелания и выбирает категории остановок
и ограничения порядка. Явно выбранные еда, природа, красивые здания и искусство
гарантированно добавляются к целям, даже если планировщик их пропустил; остальные
интересы разбирает планировщик. По каждой категории независимо выполняется собственный
BM25: до трёх подходящих документов, затем ранжирование входящих в них мест
вторым BM25. До пяти найденных мест с координатами поступают в JEV для выбора
основной и запасной точки. ID результата сверяются с кандидатами; места берутся
из корпуса. JEV при недоступности использует порядок BM25. OSRM оптимизирует
путь с учётом ограничений планировщика и строит пешую геометрию. Критерии JEV
содержат исходные тексты, которые считаются данными, а не инструкциями.

Если часть остановок не найдена, возвращаются найденные места и предупреждение
«Тестовый режим, мест пока не много» с перечнем отсутствующих категорий. Если
не найдена ни одна точка, API отвечает 422. Неизвестный город — 422; неверный
ответ или неизвестный ID — 502; ошибка планировщика, LLM или OSRM — 503.

Категории корпуса сопоставляются существующим правилам `classify_rubric`. Для
архитектуры учитываются достопримечательности, а также найденные BM25 культурные
места, в тексте которых упомянуто здание или архитектура. Упоминание не гарантирует архитектурной
ценности; при недостатке подтверждённых сведений нельзя выдумывать места.

Прямой benchmark использует обычную выдачу BM25 по полному вопросу и 30 исходным
документам. Поэтапная выдача маршрута не является top-3 одного запроса benchmark
и проверяется отдельно. В логах записываются категория, ID документов и баллы; пользовательские пожелания в эти записи не
добавляются. Индексы строятся при создании генератора. Векторный поиск и
эмбеддинги не используются. TRIP_GENERATOR_FACTORY позволяет подключить другой
совместимый генератор.
