# Продукт

Приложение составляет маршрут по городу на 1–7 дней с учётом интересов.

**Вход:** город, интересы, число дней и дата начала не раньше сегодняшней.
Интересы: дети, еда, природа, архитектура, искусство, активный отдых, необычные места.

**Результат:** описание поездки, карточки дней, список мест и карта каждого дня.
Нумерация мест в списке и на карте совпадает.

## Готовность

В `plans-for-travelers` работает интерфейс с демонстрационными маршрутами.


## Требования

- Утверждено: маршрут строится на выбранные 1–7 дней, с отдельным списком мест
  и картой для каждого дня.
- Собственный BM25 и одинаковая предобработка документов и запроса.
- LLM использует только найденные места; каждое место имеет ID источника.
- Если сведений нет, система сообщает об этом, без догадок.
- Окончательный корпус для текущей контрольной точки — места Иванова.
  Другие города в эту контрольную точку не входят.
- Русский язык; утверждённый дизайн сохраняется.

Бронирование, аккаунты и сохранение поездок между сеансами не предусмотрены.
Проверки: [сценарий](scenarios.md) и [benchmark](../../benchmark/README.md).
