# Продукт

Приложение составляет пеший маршрут по Иванову на один день с учётом интересов.
Вход: город, интересы, дата не раньше сегодняшней и необязательные пожелания.
Интересы: дети, еда, природа, архитектура, искусство, активный отдых, необычные места.
Результат: описание прогулки, список мест и интерактивная карта.

Планировщик определяет остановки, собственный BM25 находит документы и места
для каждой остановки, JEV выбирает найденные точки, а OSRM строит пеший путь с
учётом ограничений порядка. Названия, адреса и координаты берутся из корпуса.
Если подходящих мест не хватает, показывается «Тестовый режим, мест пока не много»;
отсутствующие сведения не выдумываются. Поэтапная выдача маршрута и прямой
benchmark BM25 проверяются отдельно.

Многодневного режима нет. Векторный поиск, эмбеддинги и база для поиска не нужны.
Дизайн и существующий однодневный интерфейс сохраняются.
Бронирование, аккаунты и сохранение поездок не предусмотрены.
