# Сценарий

1. Выбрать город и интересы, при желании добавить пожелания.
2. Выбрать дату прогулки не раньше сегодняшней и проверить настройки.
3. Отправить запрос: FastAPI → собственный BM25 → LLM → OSRM.
4. Увидеть карту и карточки мест однодневного маршрута.

BM25 возвращает три документа; LLM выбирает места только внутри них.
Неизвестный город или отсутствие найденных мест — 422, сбой LLM или OSRM — 503.
Неправильный ответ модели — 502. Ошибка показывается существующим интерфейсом.
При нехватке мест описание дня содержит «Тестовый режим, мест пока не много».

## Текущий однодневный интерфейс

На экране города первыми расположены Иваново и Москва; остальные предложенные
города отключены. Ручной ввод также принимает только эти два города. Доступность
маршрута определяется данными сервера: наличие Москвы в списке не означает, что
её корпус уже подключён. Выбор длительности убран: поездка на один день, дата
выбирается в календаре. API принимает только один день (`days: 1`).

Экран поездки показывает карту маршрута, затем карточки мест первого дня в
порядке маршрута. Карточка открывает экран места с названием, описанием,
адресом и интерактивной картой только этого места; кнопок выбора дня и списка
остальных мест на экране места нет. При отсутствии адреса или описания это
прямо обозначается, сведения не выдумываются.

Под календарём не показывается повторяющийся блок «Начало — Конец». После
последней карточки места на экране поездки сохраняется нижний отступ. Подпись
«Прогулка с детьми и природой», если она пришла в описании поездки, отображается
как «Прогулка с детьми и время на природе».

После выбора интересов пользователь может на отдельном экране добавить текстовые
пожелания к маршруту. «Далее» сохраняет введённый текст и открывает выбор даты;
пустой текст означает отсутствие пожеланий. «Назад» возвращает к интересам без
сохранения изменений, верхняя кнопка «Отменить» сбрасывает поездку. Возврат с
выбора даты открывает экран пожеланий с сохранённым текстом. На экране проверки
настроек показывается блок пожеланий с кнопкой редактирования; после сохранения
изменений пользователь возвращается на экран проверки. Сохранённое пожелание
передаётся в поле `prompt` запроса на генерацию.
На экране маршрута кнопка «Начать новый маршрут» открывает подтверждение:
«Вы уверены, что хотите начать сначала? Ваш прогресс заполнения будет утерян».
При подтверждении поездка сбрасывается и открывается выбор города; при отмене
пользователь остаётся на текущем маршруте.

Если мест недостаточно для выбранного числа дней, в карточках дней, для которых
не хватает мест, показывается «Тестовый режим, мест пока не много».
Используются только найденные места, без выдуманных дополнений.
