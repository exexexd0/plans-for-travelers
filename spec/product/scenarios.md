# Сценарии

Описание основано на реальном фронтенде из `app/frontend`. Скриншоты каждого экрана лежат в [`design/screens`](../../design/screens).

## Основной сценарий

| № | Экран | Что делает пользователь | Что делает система |
|---|---|---|---|
| 1 | Город, «Откуда начнём?» | Вводит город или регион либо нажимает на быстрый вариант | Кнопка «Далее» неактивна, пока поле пустое. Крестик очищает поле. Повторное нажатие на выбранный быстрый вариант снимает выбор |
| 2 | Интересы, «Что важно в маршруте?» | Отмечает одну или несколько категорий | Выбранная категория подсвечивается зелёным без галочки, повторное нажатие снимает выбор. Кнопка «Далее» неактивна, пока не выбрана ни одна категория |
| 3 | Длительность, «Сколько времени у тебя есть?» | Выбирает от 1 до 7 дней, при желании меняет дату начала в календаре на экране | Дата окончания считается автоматически, дни поездки подсвечены в календаре; месяцы листаются стрелками, прошедшие дни недоступны. Дата начала не может быть раньше сегодняшней. Повторное нажатие на выбранную длительность снимает выбор; без длительности кнопка «Далее» неактивна |
| 4 | Проверка, «Проверь, всё ли верно» | Проверяет город, интересы и даты; может нажать «Изменить» у любого блока | «Изменить» возвращает на нужный шаг, введённые данные сохраняются |
| 5 | Генерация, «Секундочку...» | Ждёт | Показывает анимацию формирующегося маршрута. Сюда придёт запрос к бэкенду |
| 6 | Поездка | Читает описание, просматривает карточки дней, нажимает на карточку нужного дня | Показывает даты, город, описание и по карточке на каждый день: фотография, дата, краткий текст о местах дня. Карты на этом экране нет |
| 7 | Маршрут по дням, «Маршрут: День N» | Переключает дни, смотрит карту дня и список мест | Показывает карточку дня, карту с маршрутом только этого дня и пронумерованный список мест. Число мест в списке равно числу точек на карте, номера совпадают |

Шаги 1–3 показывают прогресс из трёх точек. «Отменить» на шагах 1–4 сбрасывает все данные и возвращает на первый экран.

## Крайние случаи

Что уже работает во фронтенде:

| Ситуация | Поведение |
|---|---|
| Поле города пустое или из одних пробелов | «Далее» неактивна |
| Введён город, которого нет среди быстрых вариантов | Принимается любой текст: проверки по корпусу пока нет |
| Не выбран ни один интерес или не выбрана длительность | «Далее» неактивна |
| Пользователь пытается выбрать прошедшую дату | Прошедшие дни в календаре недоступны; назад дальше текущего месяца листать нельзя |
| Поездка переходит через границу месяца или года | Даты считаются верно и подписываются с обоими месяцами («30 окт — 2 ноя 2026») |
| Поездка на один день | На экране маршрута нет переключателя дней, на «Поездке» одна карточка |
| «Изменить» на экране проверки | Возвращает на нужный шаг; введённое сохраняется, дальше пользователь снова идёт через «Далее» |
| «Отменить» на шагах 1–4 | Сбрасывает все данные и возвращает на первый экран без подтверждения |
| «Назад» с экрана «Поездка» | Возвращает на проверку; маршрут при повторном проходе строится заново |
| Страница перезагружена | Все данные теряются: между сеансами ничего не сохраняется |

При работе с бэкендом:

| Ситуация | Поведение |
|---|---|
| LLM недоступна | Маршрут собирается без неё, по порядку ранжирования |
