# plans-for-travelers

RAG над списком достопримечательностей. Пользователь выбирает город и интересы, приложение находит подходящие места поиском BM25 и с помощью LLM собирает из них маршрут по дням.

Учебный проект (НИРС), МГТУ им. Н. Э. Баумана, кафедра ИУ5, курс «Оперативный анализ данных».


## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
cd app/frontend
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`. На телефоне оно занимает весь экран, на компьютере показывается в рамке 390×844.

Проверка типов и сборка: `npm run build` (результат в `app/frontend/dist`).

## Основной сценарий

1. **Город** — пользователь вводит город или регион либо выбирает из быстрых вариантов.
2. **Интересы** — отмечает одну или несколько категорий из семи.
3. **Длительность** — выбирает от 1 до 7 дней и дату начала.
4. **Проверка** — видит все настройки и может вернуться к любой.
5. **Генерация** — экран ожидания, пока собирается маршрут.
6. **Поездка** — даты, город, краткое описание и карточки дней.
7. **Маршрут по дням** — карта выбранного дня и пронумерованный список мест.

Подробно, с крайними случаями: [spec/product/scenarios.md](spec/product/scenarios.md). Скриншоты экранов: [design/](design/).

## Структура репозитория

```
README.md            что это, запуск, сценарий, команда
AGENTS.md            правила для кодингового агента
CHANGE_HISTORY.md    журнал изменений
spec/
  product/
    product.md       пользователь, задача, вход и выход, ограничения
    scenarios.md     сценарий по экранам и крайние случаи
  tech/
    architecture.md  компоненты, стек, формат API
    rag.md           что реализовано в части поиска и LLM
app/
  frontend/          интерфейс: React + Vite + TypeScript
tests/               тесты (появятся вместе с бэкендом)
benchmark/           набор запросов и результаты метрик
design/              скриншоты экранов и ссылки на макеты
```

## Подход

Работаем по Spec-Driven Development: сначала фиксируем поведение и способ проверки в `spec/`, затем делим работу на задачи и только потом меняем код. Правила для агента — в [AGENTS.md](AGENTS.md).
