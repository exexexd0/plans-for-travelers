## Эталоны обычных вопросов

Порядок свободный. Требуется ровно по одному месту каждой указанной категории, без лишних остановок. Допустимы разные типы внутри широкой категории: например, музей или театр для культуры, кафе или ресторан для питания. Категории определяются текущим `classify_rubric` в `app/pipeline/rag/categories.py`.

Релевантен любой документ, содержащий место хотя бы одной запрошенной категории. В `questions.json` перечислены все такие документы; у каждого обычного вопроса их больше трёх. Примеры взяты из сохранённых ответов и сверены с корпусом; другие подходящие места тоже допустимы.

## Q11–Q15: запросы без подтверждённого ответа

Корректный отказ: приложение явно сообщает, что обязательное условие нельзя подтвердить по имеющимся данным, и не предлагает неподтверждённые места как удовлетворяющие запросу. Релевантных документов, подтверждающих обязательное условие, нет: `relevant_ids = []`.

HTTP 503, тайм-аут, пустая страница или общая ошибка «не удалось построить маршрут» не считаются корректным отказом. Нынешний пайплайн может не пройти эти сценарии: они проверяют ограничение, а не предполагают уже реализованную поддержку отказов.

### Q11

**Интересы:** Еда (`food`).

**Пожелание:** Подбери ресторан с подтверждённым полностью безглютеновым меню. Варианты без подтверждения не предлагай.

**Почему ответа нет:** В корпусе нет подтверждения полностью безглютенового меню ресторанов; слова с основой «глютен» в текстах мест не найдены.

**Ожидается:** явное сообщение о нехватке подтверждённых данных без неподтверждённых рекомендаций.

### Q12

**Интересы:** Искусство (`art`).

**Пожелание:** Хочу посетить музей, для которого подтверждён бесплатный вход именно на выбранную дату. Если таких подтверждений нет, музей не предлагай.

**Почему ответа нет:** Есть отзывы о бесплатном входе, но нет подтверждённых условий на выбранную дату. Отзыв о прошлом посещении не подтверждает будущую стоимость.

**Ожидается:** явное сообщение о нехватке подтверждённых данных без неподтверждённых рекомендаций.

### Q13

**Интересы:** Дети, природа (`kids, nature`).

**Пожелание:** Подбери парк с подтверждённой услугой присмотра за ребёнком без родителей. Обычная детская площадка не подходит. Без подтверждения парк не предлагай.

**Почему ответа нет:** Нет подтверждения услуги присмотра без родителей в парках. Упоминание присмотра в отзыве о зоопарке не подтверждает такую услугу в парке.

**Ожидается:** явное сообщение о нехватке подтверждённых данных без неподтверждённых рекомендаций.

### Q14

**Интересы:** Красивые здания (`buildings`).

**Пожелание:** Хочу посетить здание с подтверждённым разрешённым доступом посетителей на крышу. Без подтверждения доступа варианты не предлагай.

**Почему ответа нет:** В текстах мест не найдены упоминания крыши или кровли; подтверждения разрешённого доступа нет. Смотровая площадка сама по себе не означает доступ на крышу.

**Ожидается:** явное сообщение о нехватке подтверждённых данных без неподтверждённых рекомендаций.

### Q15

**Интересы:** Еда (`food`).

**Пожелание:** Подбери кафе с подтверждённым свободным столиком на выбранную дату в 18:00. Нужны актуальные данные о свободных местах. Без подтверждения кафе не предлагай.

**Почему ответа нет:** Нет актуальных данных о занятости столиков на выбранную дату. Отзывы о столиках и бронировании не подтверждают наличие свободного столика.

**Ожидается:** явное сообщение о нехватке подтверждённых данных без неподтверждённых рекомендаций.

## Запись результатов

`python -m benchmark.run` проверяет только BM25 по полному тексту каждого вопроса,
без интересов и фильтрации по категориям. По умолчанию — вся выдача, `--k 3` — первая тройка.
Результаты и метрики: `results/bm25.json` и `results/bm25.md`.
Для метрик используются relevant_ids обычных вопросов. Условия маршрута и вопросы
без подтверждённого ответа этим поисковым прогоном не оцениваются.
Прежние результаты приложения сохранены в `results/pipeline.json` и `pipeline.md`.
