# Benchmark

Корпус: 30 документов разных категорий, 336 мест Иванова в `app/backend/data/ivanovo/`.
Места взяты из `Иваново.json`; часть отзывов дополнена с Яндекс Карт. Вопросы и эталоны — в [questions.md](questions.md)
и `questions.json`. Тексты 15 вопросов сохранены, ID релевантных документов
обновлены под подборки D01–D30. `reference_ids` остаются ID отдельных мест.

## Запуск

Из корня проекта:

```bash
source .venv/bin/activate
python -m benchmark.run
```

k=3, k₁=1,2, b=0,75. Поиск получает только вопрос, город и лимит;
эталонные ID и категории не передаются поиску. После лемматизации из документов
и запросов удаляется фиксированный список служебных стоп-слов.
Отрицания «не», «нет», «ни» и слово «без» сохраняются.

## Метрики

Recall@3 — доля релевантных документов, попавших в первую тройку.
RR@3 — 1 / позиция первого релевантного документа или 0, если такого нет.
Итоги усредняются по 10 обычным вопросам; 5 вопросов без ответа исключены.
Релевантен документ с хотя бы одним подходящим по разметке местом.

Документ релевантен, если покрывает хотя бы одну часть запроса (ИЛИ).
MRR оценивает первый полезный документ, а полноту составного сценария
проверяем отдельно руками. Эти правила подтверждены пользователем.

Одна категория представлена одним файлом. Поэтому у Q03, Q05 и Q07 теперь
один релевантный документ; у Q04, Q08 и Q09 — два. Это честная разметка,
но она пока не выполняет требование курса о трёх релевантных документах
на обычный вопрос. TODO: отдельно согласовать переработку этих вопросов;
тексты вопросов сейчас сохранены. Подменять разметку ради количества нельзя.

Новые результаты нельзя напрямую сравнивать со старыми: изменились корпус
и единица документа. Текущая выдача и метрики — в результатах ниже.

## Результаты

- [results/search.md](results/search.md) — таблица документов и метрик.
- `results/search.json` — выдача с ID, баллами и вложенными местами, адресами и координатами.

LLM пока не вызывается. После интеграции сохраняем её ответы, вручную проверяем
условия [вопросов](questions.md), считаем Accuracy по 10 обычным вопросам
и Correct Rejection Rate по 5 вопросам без ответа.

## Этап 1: стоп-слова (до обновления остальных описаний)

|---|---:|---:|
| Recall@3 | 0,825000 | 0,891667 |
| MRR@3 | 0,733333 | 0,900000 |

Корпус, вопросы, эталоны, k=3, k₁=1,2 и b=0,75 не менялись.

## После обновления всего корпуса

Во всех 30 JSON удалён общий `text`; поисковое содержимое собирается из
описаний мест в памяти. У 325 из 336 мест есть фрагмент настоящего отзыва.
Вопросы, эталоны, стоп-слова, k=3, k₁=1,2 и b=0,75 сохранены.
Результаты: Recall@3 = 0,808333; MRR@3 = 0,883333.
Это новый корпус: результат этапа со стоп-словами выше относится к прежним текстам.
