# Benchmark BM25

Из корня проекта:

```bash
source .venv/bin/activate
python -m benchmark.run
```

Проверяется только BM25: полный текст каждого вопроса → одна выдача по корпусу.
Планировщик, API, LLM, JEV и OSRM не используются, API-ключ не нужен.
Эталонные ID и категории не передаются поиску; фильтр — только город.

По умолчанию выдача не обрезается: k равно числу документов корпуса, сейчас 30.
Оценить первую тройку: `python -m benchmark.run --k 3`.
Один вопрос: `python -m benchmark.run --question Q01`.

Результаты: `results/bm25.json` и [results/bm25.md](results/bm25.md).
Они перезаписываются при запуске. Отчёт содержит вопросы, эталоны,
ранжированные ID и баллы, Recall@k и RR@k для каждого обычного вопроса,
средний Recall@k и MRR@k. Глубина MRR совпадает с k.

Метрики считаются по 10 обычным вопросам с одинаковым весом, без усреднения
по категориям. Пять вопросов без ответа сохраняются с выдачей, но исключаются
из метрик. BM25 не оценивает правильность маршрутов и корректность отказов.
Текущий набор содержит широкие категории и перефразировки; он не является
независимым набором десяти разных тем.

Прежние результаты приложения в `results/pipeline.json` и `pipeline.md`
сохранены; этот запуск их не изменяет.
