По требованиям курса необходимо подготовить:

- 30 документов с ID.
- 10 обычных вопросов: эталонный ответ и минимум 3 релевантных документа на каждый.
- 5 вопросов без ответа в корпусе: ожидается отказ.

Сохранить выдачу поиска и ответ системы для каждого вопроса.
Посчитать Recall@k и MRR по обычным вопросам, Accuracy ответов из 10
и Correct Rejection Rate из 5.

результаты — в `results/`. Использовать те же модели и поиск из `app/backend/`,
не создавать вторую реализацию BM25. Корпус — в `app/backend/data/`.
